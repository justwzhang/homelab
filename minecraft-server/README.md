### Container Description

This is a Docker Compose file for running a Minecraft server. Both vanilla and modded.

### Quick Start Guide

1. Update the `TYPE`, `VERSION`, and `NEOFORGE_VERSION` environment variables with your desired settings.
2. Run in portainer
3. Access the Minecraft server at <your-domain-name>.

### Extra Information

* Make sure to point the volumes to the location of the root of the server files.
* Make sure to update the environment variables with your desired settings.
* If you encounter any issues, refer to the [Minecraft documentation](https://www.minecraft.net/en/download/server).
