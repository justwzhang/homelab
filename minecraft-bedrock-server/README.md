### Environment Variables

### Container Description

This is a Docker Compose file for running a Minecraft Bedrock Server.

### Quick Start Guide
1. Run the docker compose in Portainer
2. Access the Minecraft Bedrock Server at <http://your-domain-name:19132>.

### Extra Information

* Make sure to update the environment variables with your desired settings.
* Change the volumes to point to the root of the bedrock server files.
* If you encounter any issues, refer to the [Minecraft Bedrock Server documentation](https://github.com/itzg/minecraft-bedrock-server).
