# README

### Environment Variables

| Variable | Description | Where to Obtain |
| --- | --- | --- |
| PASSWORD | Pi-hole password | Create a new Pi-hole user and set the password.

### Container Description

Pi-hole is a network-wide ad blocker.

### Quick Start Guide

1. Update the `PASSWORD` environment variable with your actual Pi-hole user password.
2. Run in portainer.
3. Access the Pi-hole dashboard at <http://your-domain-name:8090>.

### Extra Information

* Make sure to update the `PASSWORD` environment variable with your actual user password.
* If you encounter any issues, refer to the [Pi-hole documentation](https://docs.pi-hole.net/).
